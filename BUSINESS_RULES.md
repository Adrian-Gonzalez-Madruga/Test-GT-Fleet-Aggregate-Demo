# Business Rules

## Source of Rules
This document stores business/domain constraints learned over time from:
- Explicit user requirements.
- Product behavior requests.
- Stable inferred domain policies.

## Current Rules
- Preserve and refine business rules as cumulative project knowledge grows.
- If business requirements conflict, prefer the latest explicit user instruction and document the change.
- Update this file whenever new domain rules are discovered or inferred with high confidence.

## Rule Maintenance Protocol
When adding a rule:
1. Describe the business behavior or policy clearly.
2. Add scope/context so the rule is actionable.
3. Merge similar rules to avoid contradictions.
4. Mark uncertain inferences as provisional until confirmed.
