# Test-GT-Fleet-Aggregate-Demo

## How To Use Codex Guidance Files
This project includes three persistent guidance documents for Codex:
- `CODEX.md`: project context, baseline architecture, and Codex run instructions.
- `TECHNICAL_RULES.md`: technical constraints and engineering guardrails.
- `BUSINESS_RULES.md`: product/domain behavior and business constraints.

Expected usage on each Codex run:
1. Read all three files first.
2. Use them as default decision context while implementing changes.
3. Update `CODEX.md` with durable, relevant learnings.
4. Add or refine rules in `TECHNICAL_RULES.md` and `BUSINESS_RULES.md` when new rules are learned or inferred.
